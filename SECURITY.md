# Security

This is a personal homelab repository. It is not supported software and comes with no guarantees.

## Reporting a vulnerability

Use GitHub private vulnerability reporting: open the **Security** tab, then **Report a vulnerability**.
Please do not open public issues or pull requests for security problems.

## Secrets

Secrets in this repository are encrypted (SealedSecrets, SOPS, Ansible Vault). Plaintext secrets are not
expected here; if you find one, report it as above.
